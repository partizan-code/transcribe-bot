# Обработка медиа

## Форматы и проверка входа

Поддерживаются MP3, WAV, FLAC, OGG/Opus, M4A/AAC, MP4/MOV, MKV/WebM.
Telegram-вложения `voice`, `audio`, `video` и `document` проходят общий конвейер.
Расширение и MIME документа — только предварительный фильтр: разрешённое
расширение либо MIME с префиксом `audio/` или `video/` допускает дальнейшую проверку.

После скачивания [media.py](../media.py) запускает ffprobe и читает JSON с
дорожками, длительностью контейнера и потоков. Требуются аудиодорожка и хотя бы
одна конечная положительная длительность. Для лимита берётся максимальное
пригодное значение длительности; неопределимая длительность считается ошибкой.

Повреждённые и неподдерживаемые файлы, плейлисты и записи без аудио отклоняются.
URL не принимаются как задания. Разрешены только локальный протокол `file` и
демультиплексоры `mp3,wav,flac,ogg,mov,matroska,webm,aac`; FFmpeg/ffprobe не должны
загружать вложенные сетевые ресурсы. Обложка `attached_pic` не считается видеодорожкой.

Точные прикладные лимиты размера и длительности заданы в
[конфигурации](SETUP.md#константы-приложения). Извлечение аудио после скачивания
не увеличивает допустимый размер исходного видео. Прикладной лимит выбран
консервативно для стандартного Telegram Bot API; проект не использует отдельный
локальный Bot API server для больших файлов.

## Выборочное перекодирование

Аудио, прошедшее проверку, передаётся без перекодирования, если не обнаружено
видео и вложение не имеет Telegram-тип `video`. Локальная проверка не является
гарантией успешного декодирования записи внешним провайдером.

При наличии видео или Telegram-типе `video` FFmpeg выбирает первую аудиодорожку
через `-map 0:a:0`. В AssemblyAI передаётся WAV: PCM s16le, mono, 16 kHz.
Видео, субтитры, дополнительные дорожки и метаданные в выходной файл не включаются.
Полученный WAV повторно проверяется ffprobe.

## Временная шкала

Извлечение использует `-copyts`, `-start_at_zero` и
`aresample=async=1:first_pts=0`. Эта комбинация сохраняет ведущие паузы и смещение
начала аудио относительно видео с учётом нормализации начала входа.
При положительном смещении перед звуком добавляется тишина. Аудио не
дополняется до всей длительности видео, если дорожка закончилась раньше.

Сохранение смещения проверяется локальным тестом на синтетическом видео с двумя
аудиодорожками. Он не подтверждает точность меток AssemblyAI на реальных записях;
границы тестирования описаны в [TESTING.md](TESTING.md).

## Ограничение локальных ресурсов

Subprocess запускаются через `asyncio.create_subprocess_exec` списком аргументов,
без shell и stdin. Диагностика stderr не сохраняется; stdout ограничен
1 000 000 байт. Для декодирования/кодирования указывается один поток.

Одна операция ограничена `MEDIA_TIMEOUT`. При тайм-ауте, отмене или другом
выходе ещё работающий процесс завершается через `kill()`, затем ожидается `wait()`.
Извлечение ограничено `MAX_DURATION_SECONDS + 1` секунд и `-fs 128000000`;
после него размер WAV должен быть строго больше 44 и меньше 128 000 000 байт.
Это прикладные ограничения, а не полная изоляция процесса средствами ОС.
