# Настройка и запуск

## Требования

- Python 3.13: версия задана в [`.python-version`](../.python-version);
  `requires-python` в [pyproject.toml](../pyproject.toml) допускает `>=3.13`.
- [uv](https://docs.astral.sh/uv/) для управления `.venv` и зависимостями.
- Системные [FFmpeg и ffprobe](https://ffmpeg.org/download.html) в `PATH`.
  Они нужны и для аудио: перед транскрибацией всегда выполняется проверка ffprobe.
- Токен Telegram-бота, API key AssemblyAI и Telegram user ID разрешённых пользователей.

Команды выполняются из корня клона проекта. Для Windows и macOS используются
одни и те же команды uv; установите подходящие системные инструменты для своей ОС.

## Окружение

```sh
uv sync --locked
```

Команда создаёт проектное `.venv` и устанавливает зависимости, включая группу
`dev`, из [uv.lock](../uv.lock). Флаг `--locked` требует согласованного lockfile
и не разрешает его обновление; поведение описано в
[документации uv](https://docs.astral.sh/uv/concepts/projects/sync/).
Отдельных задач mise и шага сборки в проекте нет.

Проверьте доступность системных инструментов:

```sh
ffmpeg -version
ffprobe -version
```

При необходимости в `FFMPEG` и `FFPROBE` в [config.py](../config.py) можно указать
полные пути к исполняемым файлам. Это константы Python, а не параметры `.env`.
До запуска polling приложение проверяет наличие обоих инструментов через `shutil.which`.

## Переменные окружения

Скопируйте [`.env.example`](../.env.example) в `.env` рядом с `config.py`.
В шаблоне значения пустые; заполните их локально:

| Переменная | Значение |
| --- | --- |
| `BOT_TOKEN` | Токен вашего Telegram-бота. |
| `ASSEMBLYAI_API_KEY` | Ключ вашего аккаунта AssemblyAI. |
| `ALLOWED_USER_IDS` | Telegram user ID через запятую; пустой список запрещает доступ всем. |

Не сохраняйте реальные ключи в документации или отслеживаемых файлах. `.env`
исключён из Git. Бот принимает задания только от людей из allowlist в личных чатах.

При импорте `config.py` python-dotenv загружает `.env` относительно самого модуля,
независимо от рабочего каталога, с кодировкой `utf-8-sig`. Уже заданные переменные
окружения имеют приоритет, в том числе пустые значения. При отсутствии файла
используется окружение процесса.

Только три переменные из таблицы читаются через `os.getenv`. ID преобразуются
в множество целых чисел: пробельные элементы пропускаются, повторы удаляются,
нечисловой элемент вызывает ошибку при импорте. Диапазон ID не проверяется.
Общей валидации конфигурации и класса `Settings` в `config.py` нет; синтаксис
токена проверяется aiogram при создании `Bot`. Не считайте успешное создание
клиентов подтверждением действительности ключей или доступности сервисов.

## Константы приложения

Остальные настройки заданы непосредственно в [config.py](../config.py).
Одноимённые переменные `.env` не меняют их значения.

| Константа | По умолчанию | Назначение |
| --- | --- | --- |
| `MAX_FILE_BYTES` | `20000000` | Максимальный размер исходного вложения в байтах. |
| `MAX_DURATION_SECONDS` | `3600` | Максимальная длительность записи в секундах. |
| `WORKERS` | `2` | Число одновременно обрабатываемых заданий. |
| `QUEUE_SIZE` | `10` | Ожидающие задания, включая резервирования при постановке. |
| `DOWNLOAD_TIMEOUT` | `120` | Общее время получения метаданных и скачивания, секунд. |
| `MEDIA_TIMEOUT` | `180` | Лимит одной операции ffprobe/FFmpeg, секунд. |
| `TRANSCRIPTION_TIMEOUT` | `1800` | Общее время загрузки, отправки и ожидания AssemblyAI, секунд. |
| `REQUEST_TIMEOUT` | `60` | HTTP-тайм-аут SDK и лимит отдельной Telegram-операции, секунд. |
| `DELIVERY_ATTEMPTS` | `2` | Максимальное число попыток отдельной операции доставки. |
| `FFMPEG` / `FFPROBE` | `ffmpeg` / `ffprobe` | Имена команд или полные пути к инструментам. |
| `ERROR_LOG_PATH` | `error.log` рядом с `config.py` | Путь журнала ERROR+. |

## Запуск

```sh
uv run --locked python main.py
```

Команда запускает polling Telegram. Отправка задания приведёт к передаче аудио
в AssemblyAI и может вызвать платную операцию. Порядок использования описан в
[README](../README.md#использование); обработка данных и диагностика — в
[OPERATIONS.md](OPERATIONS.md).

`transcribe.py` — библиотечный модуль без самостоятельного примера запуска.
Для изолированных проверок используйте [TESTING.md](TESTING.md).
