# Техническая документация

Этот каталог содержит подробности настройки и реализации Transcribe Bot.
Обзор возможностей и синтетическая демонстрация — в [корневом README](../README.md).

| Документ | Содержание |
| --- | --- |
| [SETUP.md](SETUP.md) | Требования, окружение, конфигурация и запуск. |
| [ARCHITECTURE.md](ARCHITECTURE.md) | Модули, очередь, жизненный цикл, формат результатов. |
| [MEDIA.md](MEDIA.md) | Форматы входа, ffprobe, FFmpeg и сохранение временной шкалы. |
| [TESTING.md](TESTING.md) | Изоляция, команды тестов, Ruff и границы проверок. |
| [OPERATIONS.md](OPERATIONS.md) | Статусы, ошибки, доставка, журналы и обработка данных. |
| [IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md) | Выполнение плана первой версии, подтверждённые проверки и оставшиеся шаги. |

План отделяет реализованный конвейер от незавершённой предварительной валидации
настроек и неподтверждённых реальных интеграций. Текущая конфигурация описана
в [SETUP.md](SETUP.md).

Правила разработки и безопасности — в [AGENTS.md](../AGENTS.md).
